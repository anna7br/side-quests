# Side Quests

Small tools built for myself and friends, published at **https://anna7br.github.io/side-quests/**.

| Project | What it is | Live |
|---|---|---|
| [arrive-awake](arrive-awake/) | Night-train alarm that wakes you N minutes before the real, delay-adjusted arrival (PWA, EN/DE, live data + GPS fallback, push alarm backend on Cloudflare Workers) | https://anna7br.github.io/side-quests/arrive-awake/ |
| [stechen-schreiber](stechen-schreiber/) | Score keeper for the Austrian card game *Stechen* (single HTML file, German, works offline) | https://anna7br.github.io/side-quests/stechen-schreiber/ |

The overview page (`index.html`) reuses the stylesheet of [anna7br.github.io](https://github.com/anna7br/anna7br.github.io) (copied to `assets/`).
